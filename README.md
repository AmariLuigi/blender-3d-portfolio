## 🌐 Live GitHub Pages Deployment

This repository is ready to be published to **GitHub Pages** instantly:

1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: 3D Motion & Kinetic Art Portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. In your GitHub repository:
   - Navigate to **Settings** > **Pages** (under Code and automation).
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select branch **`main`** and folder **`/ (root)`** (or **`/docs`**).
   - Click **Save**.
3. Your portfolio will go live at:
   `https://<your-username>.github.io/<your-repo-name>/`

## ✨ Features & Architecture

- **Clean & 100% Video-Focused**: Dedicated strictly to showcasing your finished 3D artwork without raw code or technical clutter.
- **Dual Stream Engine**:
  - ⚡ **1080p Fast Stream**: Encoded with `+faststart` H.264 for zero-latency hover preview and mobile streaming.
  - 💎 **4K UHD Master (3840×2160)**: Visually lossless master stream with one-click in-player switching.
- **Interactive Cinema Theater**:
  - Full-screen immersion with custom sleek player controls.
  - Keyboard shortcuts (`Space` to Play/Pause, `F` for Fullscreen, `←`/`→` to scrub, `Shift + ←/→` to navigate, `Esc` to close).
  - Technical Dossier drawer detailing render engine, lighting setup, and motion choreography for every piece.
- **Category Filter Tabs**:
  - **Art Nouveau Kinetics**: Organic gold-filigree curved lattices and ambient occluded lighting.
  - **Liquid Chrome & Fluid**: Mercury-like fluid tension and sharp studio specular reflections.
  - **Cyberpunk & Sci-Fi**: Volumetric neon emission cores and dynamic trailing chase cams.
  - **Procedural Ocean**: Atmospheric subsurface water scattering and foam displacement.
